---
title: "Tisa Transfer Request webhook"
version: 1
webhook: true
---

This webhook notifies that a cash ISA transfer request has been sent to the ceding party for a transfer in, or has been received from the acquiring party for a transfer out.

#### Request body

```json
{
    "Type": "TisaTransferRequest",
    "Version": 1,
    "Payload": {...},
    "Nonce":
}
```

#### Payload Fields

| Field | Type | Format | Required | Min-Max length | Pattern | Description |
| ----- | ---- | ------ | -------- | -------------- | ------- | ----------- |
| `SequenceNumber` | integer | - | No | - | - | Sequence number indicating the order of webhook events for this transfer. Minimum value: `0`. |
| `MessageId` | string | - | Yes | 35-35 | `^[A-Z0-9\-]{35}$` | The unique message reference from the XML. |
| `TimestampCreation` | string | date-time | Yes | - | - | Timestamp created. |
| `TransferDateRequested` | string | date-time | Yes | - | - | The date the transfer request was received by the acquirer. |
| `EffectiveDateOfTransfer` | string | date-time | Yes | - | - | The effective date of the transfer. |
| `Surname` | string | - | Yes | - | - | Surname of the customer. |
| `GivenName` | string | - | Yes | - | - | Given name (first name) of the customer. |
| `BirthDate` | string | date-time | Yes | - | - | Birth date of the customer. |
| `NINumber` | string | - | Yes | - | - | National Insurance number of the customer. |
| `AddressLines` | array | - | Yes | - | - | Address of the customer. |
| `PostCode` | string | - | Yes | - | - | Post code of the customer. |
| `Country` | string | - | Yes | 2-2 | `^[A-Z]{2}$` | Country of the customer. Must be a valid ISO 3166-1 alpha-2 country code, for example, `GB` for the United Kingdom. |
| `CedingPartyClientAccountIdentification` | string | - | Yes | - | - | Sort code and account number of the investor in the ceding party's system, or alternative account identifier (Roll Number). |
| `AcquiringPartyClientAccountIdentification` | string | - | Yes | - | - | Sort code and account number of the investor in the acquiring party's system, or alternative account identifier (Roll Number). |
| `CedingPartySun` | string | - | Yes | 6-6 | `^[0-9]{6}$` | Ceding party's SUN (Service User Number), a unique identifier for the ISA manager in the Pay.UK service. |
| `AcquiringPartyCollectionAccount` | string | - | Yes | - | - | Sort code and account number of the account the ceding party is to send the transfer funds to. |
| `AcquiringPartySun` | string | - | Yes | 6-6 | `^[0-9]{6}$` | Acquiring party's SUN (Service User Number), a unique identifier for the ISA manager in the Pay.UK service. |
| `Urn` | string | - | Yes | 18-18 | `^[A-Z0-9]{18}$` | Unique reference number. |
| `ResidualCashIndicator` | boolean | - | No | - | - | Indicates whether the ISA contains a residual cash asset for transfer. Only relevant for stocks and shares ISA transfers. |
| `CashComponentIndicator` | boolean | - | No | - | - | Indicates whether the ISA contains a residual cash asset for transfer. Only relevant for stocks and shares ISA transfers. |
| `ExtendedCurrentYearType` | string | - | Yes | - | `DEFAULT`, `INCLUDECURRENT`, `EXCLUDECURRENT` | Include or exclude the current year subscriptions from the transfer. |
| `IncludeAllPreviousYears` | boolean | - | No | - | - | Indicates whether the investor wants to transfer all previous years. |
| `AmountFromPreviousYearsSubscription` | decimal | - | No | - | - | Partial amount that can be made up of previous years subscriptions only, or a combination of the current and previous years subscriptions. |
| `EarlyClosureWaiver` | boolean | - | No | - | - | Indicates whether the customer has acknowledged and agreed to pay a fee to exit a fixed-term product early. |
| `DateOfFirstSubscription` | string | date-time | Yes | - | - | The date of the first subscription made by the customer in the current tax year. |
| `LatestPaymentDate` | string | date-time | No | - | - | The date by which payment must be made. |
| `AcquiringPartyProductType` | string | - | No | - | `CASH`, `STCK` | Used to indicate the class of assets permitted by the acquiring party's product. |
| `TotalAmountYearToDate` | decimal | - | Yes | - | - | Maximum amount (excluding interest and withdrawals) that could be transferred by the ceding party under current year subscription. |
