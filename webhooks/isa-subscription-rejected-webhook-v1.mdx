---
title: "ISA Subscription Rejected webhook"
version: 1
webhook: true
---

This webhook confirms the ISA subscription (payment into the ISA) has failed and provides a rejection reason.

#### Request body

```json
{
    "Type":"IsaSubscriptionRejected",
    "Version":1,
    "Payload": {...},
    "Nonce":
}
```

#### Payload Fields

| Field | Type | Format | Required | Min-Max length | Pattern | Description |
| ----- | ---- | ------ | -------- | -------------- | ------- | ----------- |
| `AccountId` | string | uuid | Yes | - | - | The unique identifier of the ISA which was the creditor of the subscription. |
| `RejectionReasons` | array | - | Yes | - | - | An array of human-readable reasons why the subscription was rejected. At least one item. |
| `EndToEndId` | string | - | No | 0-35 | - | The end-to-end identifier of the subscription. |
| `Amount` | decimal | - | Yes | - | - | The amount of the subscription. |
| `TaxYear` | string | - | Yes | 5-5 | `^[0-9]{2}/[0-9]{2}$` | The tax year. |
| `CashIsaStatus` | string | - | Yes | - | `None`, `Inactive`, `Active`, `Cancelled`, `Closed`, `TransferredOut` | The status of the ISA. |
| `NetSubscription` | decimal | - | Yes | - | - | The net subscription for the ISA in the tax year. |
| `RemainingSubscriptionAllowance` | decimal | - | Yes | - | - | The remaining subscription allowance for the ISA in the tax year. |
| `AnnualAllowanceUsed` | decimal | - | No | - | - | The maximum value the net subscription reaches in the tax year. |
| `PaymentMethodType` | string | - | No | - | `Transfer`, `FasterPayments`, `Bacs`, `CHAPS` | The payment method type of the subscription. |
| `DebtorAccountIdentifiers` | string | - | No | - | - | The account identifiers of the debtor account of the subscription, for example, `IBAN` or `BBAN`. |
| `NominatedAccountIdentifiers` | string | - | No | - | - | The account identifiers of the nominated account for the ISA, for example, `IBAN` or `BBAN`. |
| `DeclarationExpiryDate` | string | date-time | No | - | - | The date the declaration expires (UTC). If null, the declaration is valid indefinitely. |
| `CustomerEligibilityStatus` | string | - | Yes | - | `NotProvided`, `Eligible`, `Ineligible` | The eligibility status of the customer. |
| `CustomerEligibilityStatusReasons` | array | - | No | - | `NotProvided`, `CustomerAddressInvalid`, `CustomerResidencyInvalid`, `CustomerNationalInsuranceNumberInvalid`, `CustomerDateOfBirthInvalid` | The reasons for the eligibility status of the customer. |
| `TransferOutStatus` | string | - | Yes | - | `NotProvided`, `None`, `InProgress`, `FullTransferOutComplete`, `AwaitingFullTransferOutConfirmation`, `AwaitingFullFundReturn`, `Rejected` | The transfer out status of the ISA. |
