---
title: "Tisa Transfer Status Update webhook"
version: 1
webhook: true
---

This webhook notifies you that the status of an automated cash ISA transfer has been updated.

**Note:** This webhook's `SequenceNumber` will read `3`, `4`, then `5` as the status of the transfer progresses. This follows `SequenceNumber: 2` from the `TisaTransferAccepted` webhook, which is sent when the transfer is accepted.

#### Request body

```json
{
    "Type": "TisaTransferStatusUpdate",
    "Version": 1,
    "Payload": {...},
    "Nonce":
}
```
