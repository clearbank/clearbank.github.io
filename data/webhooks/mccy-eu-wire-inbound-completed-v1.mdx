---
title: "Cross-border Inbound Payment Completed webhook"
version: 1
webhook: true
---

This webhook confirms that you've received a cross-border wire payment and your account has been credited. Use the `TransactionId` to match the payment to the credit on your account.

If the payment doesn't include an end-to-end identification, or the debtor or creditor name is missing, you'll receive the value `NOTPROVIDED` in that field.

#### Request body

```json
{
  "Type": "Payments.CBEU.CrossBorder.InboundPaymentCompleted",
  "Version": 1,
  "Payload": {...},
  "Nonce":
}
```

#### Payload fields

| Field                       | Type   | Format | Required | Min-Max length | Description                                                                                                                                                                              |
| --------------------------- | ------ | ------ | -------- | -------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PaymentId`                 | string | uuid   | Yes      | 36-36          | A unique identifier to reference this inbound payment. This has the same value as the `UETR` in `PaymentIdentification`.                                                                 |
| `TransactionId`             | string | uuid   | Yes      | 36-36          | A unique identifier assigned by ClearBank to reference the credit transaction related to this inbound payment.                                                                           |
| `PaymentIdentification`     | object | -      | Yes      | -              | Set of elements used to reference the payment instruction. See `PaymentIdentification`.                                                                                                  |
| `InterbankSettlementAmount` | object | -      | Yes      | -              | Amount of money moved between the instructing agent and the instructed agent. This is the amount credited to your account. See `InterbankSettlementAmount`.                              |
| `DebtorAccount`             | object | -      | No       | -              | Account of the debtor that the payment was sent from. Can be `null`. See `CashAccount`.                                                                                                  |
| `DebtorAgent`               | object | -      | Yes      | -              | Financial institution servicing the account of the debtor. See `BranchAndFinancialInstitutionIdentification`.                                                                            |
| `CreditorAccount`           | object | -      | No       | -              | Your account that the payment was credited to. Can be `null`. See `CashAccount`.                                                                                                         |
| `CreditorAgent`             | object | -      | Yes      | -              | Financial institution servicing the account of the creditor. See `BranchAndFinancialInstitutionIdentification`.                                                                          |
| `InstructingAgent`          | object | -      | No       | -              | Agent that instructed ClearBank to carry out the payment. Can be `null`. See `BranchAndFinancialInstitutionIdentification`.                                                              |
| `UltimateDebtor`            | object | -      | No       | -              | Ultimate party that owes an amount of money to the (ultimate) creditor. Can be `null`. See `PartyIdentification`.                                                                        |
| `Debtor`                    | object | -      | Yes      | -              | Party that owes an amount of money to the (ultimate) creditor. See `PartyIdentification`.                                                                                                |
| `Creditor`                  | object | -      | Yes      | -              | Party to which an amount of money is due. See `PartyIdentification`.                                                                                                                     |
| `UltimateCreditor`          | object | -      | No       | -              | Ultimate party to which an amount of money is due. Can be `null`. See `PartyIdentification`.                                                                                             |
| `RemittanceInformation`     | object | -      | No       | -              | Information supplied to help you match the payment with the items it's intended to settle, such as commercial invoices. Can be `null` if none was provided. See `RemittanceInformation`. |

##### PaymentIdentification

| Field                       | Type   | Format | Required | Min-Max length | Description                                                                                                                                                     |
| --------------------------- | ------ | ------ | -------- | -------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `InstructionIdentification` | string | -      | No       | 1-35           | A unique identifier assigned by the instructing party to identify the payment instruction.                                                                      |
| `EndToEndIdentification`    | string | -      | Yes      | 1-35           | A reference set by the initiating party, which is passed on unchanged throughout the end-to-end chain. If no value is set, this is `NOTPROVIDED`.               |
| `TransactionIdentification` | string | -      | No       | 1-35           | Unique identification, as assigned by the first instructing agent, to identify the transaction. It's passed on unchanged throughout the entire interbank chain. |
| `UETR`                      | string | uuid   | No       | 36-36          | A unique end-to-end transaction reference (UETR) used to track the payment end to end across the payment chain. Can be `null`.                                  |

##### InterbankSettlementAmount

| Field      | Type   | Format  | Required | Min-Max length | Pattern      | Description                                                    |
| ---------- | ------ | ------- | -------- | -------------- | ------------ | -------------------------------------------------------------- |
| `Amount`   | number | decimal | Yes      | -              | -            | The amount of the payment.                                     |
| `Currency` | string | -       | Yes      | 3-3            | `^[A-Z]{3}$` | The three-letter ISO 4217 currency code of the payment amount. |

##### CashAccount (DebtorAccount and CreditorAccount)

| Field   | Type   | Required | Min-Max length | Pattern                               | Description                                                                                                       |
| ------- | ------ | -------- | -------------- | ------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| `IBAN`  | string | No       | -              | [A-Z]{2,2}[0-9]{2,2}[a-zA-Z0-9]{1,30} | International Bank Account Number (IBAN) of the account. Can be `null`.                                           |
| `Other` | object | No       | -              | -                                     | Identification of the account, using a scheme other than IBAN. Can be `null`. See `GenericAccountIdentification`. |

##### GenericAccountIdentification

| `Identification` | string | Yes      | 1-34           | Identification of the account, as assigned by the institution that services it. |
