---
title: "CBEU Cross-border Outbound Payment Accepted webhook"
version: 1
webhook: true
---

Sent when an outbound AutoFX payment has been accepted.

#### Request body

```json
{
  "Type": "Payments.CBEU.CrossBorder.OutboundPaymentAccepted",
  "Version": 1,
  "Payload": {...},
  "Nonce":
}
```

#### Payload fields

| Field                       | Type   | Format    | Required | Min-Max length | Pattern                                                                                                                                                                   | Description                                                                                                                                                                                                                                                                                    |
| --------------------------- | ------ | --------- | -------- | -------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `TransactionId`             | string | uuid      | No       | 36-36          | `^[a-f0-9]{8}-[a-f0-9]{4}-4[a-f0-9]{3}-[89ab][a-f0-9]{3}-[a-f0-9]{12}$`                                                                                                   | Internal unique identifier for the transaction within the platform.                                                                                                                                                                                                                            |
| `EndToEndId`                | string | -         | No       | -              | `^[0-9a-zA-Z\/\\-\\?:\\(\\)\\.,''\\+](\|[0-9a-zA-Z\/\\-\\?:\\(\\)\\.,''\\+]\|[0-9a-zA-Z\/\\-\\?:\\(\\)\\.,''\\+ ]{1,33}[0-9a-zA-Z\/\\-\\?:\\(\\)\\.,''\\+])$` | End-to-end reference used to identify the payment consistently across all systems and parties involved in processing.                                                                                                                                                                          |
| `InstructionId`             | string | -         | No       | -              | `^[0-9a-zA-Z\/\\-\\?:\\(\\)\\.,''\\+](\|[0-9a-zA-Z\/\\-\\?:\\(\\)\\.,''\\+]\|[0-9a-zA-Z\/\\-\\?:\\(\\)\\.,''\\+ ]{1,33}[0-9a-zA-Z\/\\-\\?:\\(\\)\\.,''\\+])$` | Identifier assigned to a specific instruction request used to correlate client input with downstream processing.                                                                                                                                                                               |
| `Uetr`                      | string | uuid      | No       | 36-36          | `^[a-f0-9]{8}-[a-f0-9]{4}-4[a-f0-9]{3}-[89ab][a-f0-9]{3}-[a-f0-9]{12}$`                                                                                                   | Universally Unique End-to-End Transaction Reference (UUID v4) used to track the payment across the correspondent banking network.                                                                                                                                                             |
| `PaymentId`                 | string | -         | No       | -              | `^[a-zA-Z0-9_-]{0,50}$`                                                                                                                                                   | Internal identifier representing a payment instruction within the platform.                                                                                                                                                                                                                    |
| `InstructedCcy`             | string | -         | No       | 3-3            | `^[A-Z]{3,3}$`                                                                                                                                                            | The currency in which the instructed amount is expressed, given as a three-letter ISO 4217 currency code.                                                                                                                                                                                      |

| `InterbankSettlementAmount` | number | decimal   | No       | -              | -                                                                                                                                                                         | The amount settled between financial institutions as part of payment execution. This represents the settlement side of the transaction and may be either fixed or derived.                                                                                                                     |
| `PaymentValueDate`          | string | date-time | No       | -              | -                                                                                                                                                                         | The value date on which the payment is settled between financial institutions.                                                                                                                                                                                                                 |
