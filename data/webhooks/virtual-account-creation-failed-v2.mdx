---
title: "Virtual Account Creation Failed Webhook"
version: 2
webhook: true
---

This webhook notifies you when creation of a virtual account has failed.

#### Request body

```json
{
    "Type":"VirtualAccountCreationFailed",
    "Version":2,
    "Payload": {...},
    "Nonce":
}
```

#### Payload
| Element                     | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `VirtualAccountId`          | A unique ID to identify the virtual account<br /> Type: `GUID`<br /> Max. length: 36                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `ClientMoneyAccountId`      | A unique ID to identify the real (pooled) account.<br /> Type: `GUID`<br /> Max. length: `36`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `VirtualAccountIdentifiers` | **Required**<br />Virtual account identifier object. It contains `IBAN`, `BBAN`, `AccountName` and `AccountHolderLabel`. <br /><br />`IBAN`: International Bank Account Number associated with the account.<br /> Type: `string` <br /><br />  `BBAN`: Basic Bank Account number associated with the account.<br /> Type: `string` <br /><br />`AccountName`: Name of the account. <br /> Type: `string` <br /><br />`AccountHolderLabel`: The account description. <br /> Type: `string`                                                                                                                                                                |
| `Errors`                    | One or more errors that occurred during the processing of the request.<br /><br /> Example errors: `None`, `ClientMoneyAccount`, `ClientMoneyAccountId`, `ClientMoneyAccountIban`, `InstitutionId`, `AccountIban`, `AccountIbanSortCode`, `AccountIbanAccountNumber`, `AccountBban`, `AccountBbanSortCode`, `AccountBbanAccountNumber`, `AccountIdentifiers`, `AccountName`, `AccountHolderLabel`, `AccountCuid`, `AccountUpic`, `AccountIbanBankCode`, `AccountBbanBankCode`, `ClientMoneyAccountIdMissing`, `InstitutionIdMissing`, `VirtualAccountIdMissing`, `AccountModulusFailed`, `SortCodeDoesNotBelongToInstitution`, `SortCodeTypeIsIncorrect` |
| `Timestamp`                 | Date and time the virtual account creation failed.<br /> Time Zone: `UTC`<br /> Type: `DateTime`                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `Nonce`                     | Cryptographically secure number generated by ClearBank® for every single webhook. A nonce number is generated randomly and should not be used as a check for duplication.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |

    "Type": "VirtualAccountCreationFailed",

```

    "Nonce": 6719354082
}
```
