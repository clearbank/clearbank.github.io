## Overview

When you were onboarded, you registered your first API client in the ClearBank Portal (see [Register your API client](./register-your-api-client)). That first client serves as your main, authoritative client.

Once this client is set up, you can use the Client Management API to programmatically register and manage additional API clients - along with their secrets, signature keys, and permitted scopes - without returning to the Portal. This is useful if you need to manage many API clients at scale.

Every request to this API must be authenticated with an access token over mTLS and carry a valid digital signature, exactly like any other External Gateway API call. See [Using the API](./using-the-api) for access tokens and headers, and [Sign your requests](./sign-your-requests) for signing. Each operation also requires your client to have the appropriate permissions.
